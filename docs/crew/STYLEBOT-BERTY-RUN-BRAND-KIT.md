## Berty
Small boxy shop robot · round head · both arms · simple eyes. Friendly, not a mech.

## Game look
- **Timing runner** (auto-scroll) — not a free platformer  
- **2D only** — flat heats *or* drawn-perspective heats (fake depth, no 3D)  
- Gems = amber diamonds · Exit = labeled gate · Fail = shape + pink, not color alone  

## Start screen
